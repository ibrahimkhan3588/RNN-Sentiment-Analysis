# RNN-Sentiment-Analysis
A Sentiment Analysis project using a Simple Recurrent Neural Network (SimpleRNN) and Deep Learning with TensorFlow/Keras. This project analyzes Amazon product reviews and classifies them as Positive or Negative.

# Key Features:

Amazon reviews dataset

Text preprocessing and cleaning

Tokenization and sequence conversion

Padding for uniform input length

SimpleRNN model implementation

Model training and evaluation

Confusion matrix and classification report

Prediction on custom text reviews

# Technologies:

Python, TensorFlow, Keras, NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
